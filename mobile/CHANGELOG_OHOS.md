# Immich OHOS 更新日志

## 2026-09-19

> 覆盖 2026-08-23 以来：AI HDR 全量上线、合并上游 v3.2.1、EXIF 地图与备份稳定性修复。

### 本 fork 修复与增强

1. 图片 AI HDR 引擎上线：SDR 照片经 VPE 单层转换为 HLG，缩略图、预览、大图全链路生效（横拍、竖拍均支持）；VPE 瞬态失败已通过串行化与重试解决
2. 新增"图片 AI HDR"设置开关（设置 → 照片，默认开启），可随时关闭回退 SDR
3. HDR 查看器：解码与 surface 状态解耦，消除进入大图时的白闪；修复 HDR 视频滑动到 HDR 照片时的 SDR→HDR 跳变
4. 修复退出登录后无法再次登录的问题（v3.2.1 上游改写权限守卫导致 OHOS 上相册权限请求崩溃）
5. 修复详情面板地图点击无法跳转：恢复原生 onMapClick 导航主路，Flutter 层降级为兜底
6. 修复地图热力图、范围列表不更新（setBounds 拦截改为仅在查看器位于栈顶时生效）及缩略图资产 pin 点击死区
7. 地图页强制 SDR 显示，返回查看器时自动恢复 HDR
8. 修复时间线滑动时反复出现加载转圈（预加载范围恢复至合并前水平）
9. native_video_player 依赖提升，改善视频 seek 与缓冲体验
10. Flutter OHOS 引擎切换为自建 3.44.9（含 HDR 显示修复），安装包不再包含 x86 模拟器原生库
11. 服务端：恢复被 v3.2.1 合并无声覆盖的两处 fork 修复（存储模板默认值按相册目录、外部库内容校验全套测试）
12. 服务端 Docker 镜像构建与发布恢复（对齐上游 devtools 新接口），Actions 不再出现无效失败

### 上游 v3.2.1 更新（随合并带入）

1. 回忆（Memories）视图
2. 全新搜索：新搜索 API 与 Web 端新搜索界面
3. 人物管理：人物合并改进，可对分组重新运行人脸识别，分组聚类
4. 地图：在地图视口内查看资产，地图显示资产数量
5. 自动化：新增相册、归档、堆叠、恢复动作与撤销处理
6. 标签重命名（v2）、API 密钥轮换、OAuth 账户管理链接
7. 同一秒拍摄的照片按文件名排序
8. 移动端修复：同步卡死不再阻止恢复后同步、上传断线自动重发、下载不再卡在进行中、时间线按本地日期排序、分享保留原文件名、双指缩放不再跳回中心、遵循系统 24 小时制、移入锁定文件夹时彻底删除本地副本

## Mobile App

- 解决了自签名 SSL 证书无法连接服务器的问题（需先在系统设置中安装证书），对齐上游处理逻辑并自动构建 ohos_http 原生库
- 解决了登录页空地址未校验的问题
- 解决了大图页菜单操作（收藏、下载、分享等）点击失效的问题
- 解决了查看器下载浮窗点击无响应的问题，并调整布局避免遮挡
- 解决了 HDR 查看器显示设置异常的问题，优化原图预加载，大图加载完成后直接显示原图
- 解决了远程缩略图请求并发过高导致报错的问题，限制并发数并优化错误提示
- 解决了后台备份 Worker 被系统杀死后无法自动恢复的问题
- 解决了本地视频时长同步为 0 及同步日志缺失导入记录的问题
- 解决了新安装用户默认不开启备份“相簿同步”的问题，改为默认开启
- 解决了同步流请求头兼容性问题导致下载失败的问题
- 解决了动态照片识别错误及手动上传失败的问题
- 解决了应用内转码库导致安装包体积大的问题，改用 OHOS 系统转码保存动态照片
- 解决了通知未初始化导致推送不生效的问题，并补充通知设置中文翻译
- 解决了分享质量选项、通知设置中文翻译缺失的问题
- 解决了 FeatureMessage（What's New / 新变化）在 OHOS 平台不显示及翻译缺失的问题
- 解决了图片请求 `preferEncoded` 参数各平台未对齐的问题
- 移除了 Isar 数据库依赖，全面切换至 Drift，减少安装包体积
- 清理了分享临时文件

## Server

- 外部图库校验和从 hash 路径改为 hash 内容，手机端可识别本地文件已在服务端存在，避免重复上传（需在服务端设置中手动开启）
- 解决了外部图库校验和扫描队列卡顿、冲突迁移失败及迁移顺序兼容问题
- 优化外部图库导入落库批次与进度，收敛并发数
- 解决了存储模板迁移无超时、断点续传和失败追踪的问题，改为默认队列执行
- 新增 OHOS 动态照片配对接口，支持服务端实时配对和批量重扫配对
- 优化动态照片重扫任务统计信息及界面反馈
- 新增动态照片重扫管理面板（管理后台 → 队列 → 动态照片重扫），支持进度查看和结果统计
